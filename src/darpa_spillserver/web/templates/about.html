About

The DARPA Spill Information Server polls the embedded bottle server on one or more NOvA TDUs, archives the accelerator events they decode (NuMI $74, BNB $1B, the TCLK resets, the 1 Hz $8F, …), and serves them by time range and signal as CSV or JSON, with every timestamp in NOvA base time, UNIX, UTC and GPS.

Data flow: TDU /spill_history → ingest poller (asyncio task, one per source) → SQLite archive (WAL) → HTTP API (/api/…) → this web UI, darpa-spill-client (Python), darpa-spill-client-cpp and the C/C++ library.
